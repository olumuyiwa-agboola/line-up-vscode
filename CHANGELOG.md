# Change Log

All notable changes to the "line-up" extension will be documented in this file.

## [0.0.1]

- Initial release: line up selected lines by length with <kbd>Ctrl</kbd>+<kbd>R</kbd>, <kbd>Ctrl</kbd>+<kbd>R</kbd>.
- Line up C# using directives automatically on save (`lineUp.usingsOnSave`).
- Commands to line up using directives in every C# file of the current project or solution.
